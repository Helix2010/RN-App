# 周期市场：多期浏览与交易 方案

日期：2026-09-08 · 状态：已确认（§8 四项按建议方案）并实现，变更记录 `docs/changes/2026-09-08-feat-predict-series-periods.md` · 范围：RN-App（系列页、系列卡、持仓入口、网关分页）

## 1. 问题

App 的系列页只有"当期窗口"一张卡：`pickCurrentPeriod` 选出进行中（或最近的未来）一期，只有这一期能进详情下单；
历史窗口只列结果，未来窗口完全看不到。周期性（每 5 分钟一期、可以提前对下一期下注）没有体现出来。

网页版（`app/predict/crypto/[seriesSlug]/_content.tsx`）：期轨道（历史结果圆点 + 当期 + 未来 3 期 + "更早 / 更多"菜单）、
任意一期可选、未来期可交易（`market && !periodEnded`，平台对未来 5 期 `acceptingOrders=true`）、已结束期显示结果面板、
持仓页按 `seriesSlug + seriesRecurrence` 判定周期市场并带 `?event=<期事件 slug>&condition=<市场 id>` 定位到那一期（`lib/markets/positionHref.ts`）。

## 2. 用户在这个页面上要做什么

5 分钟一期决定了这页的节奏：用户停留时间短、动作重复、错一期就是白下。按使用场景列出五条路径，后面的设计都对着它们检查。

| 路径 | 用户要完成的事 | 设计要保证的 |
| --- | --- | --- |
| A 快速下注 | 进页 → 看剩余时间、参考价、现在是涨方还是跌方领先 → 点涨 / 跌 → 确认 | 三步内下单；从头到尾清楚下的是哪一期 |
| B 提前押下一期 | 当期只剩几十秒不想追，切到下一期押 | "下一期"一步可达；说明参考价开盘才定 |
| C 盯到结算 | 下完单留在页里，看走势、等结果、领取，再看下一期 | 仓位、结果、领取都在本页；翻期不把用户甩走 |
| D 从持仓回来 | 持仓页点某期仓位，看那期结果 / 领取 | 精确定位到那一期；找不到时留在当期并说明 |
| E 看节奏 | 最近几期涨跌、未来几期开盘时间 | 轨道一眼可读；历史可继续翻 |

## 3. 体验原则

1. **永远知道在看哪一期**：期窗口（如 09:10–09:15）同时出现在所选期卡、下单按钮、下单面板头部、成功提示里，四处一致。
2. **当期优先，下一期一步可达**：默认跟随当期；"下一期"芯片就在当期旁边；其它期在轨道里横滑。
3. **时间是第一信息**：倒计时用大字号；最后 30 秒变警示色并标"即将结束"；未来期显示"HH:MM 开盘 · 后开始 mm:ss"。
4. **不打断**：翻期不弹窗；有仓位的期结束时不自动跳走；没有仓位才自动跟到新一期并用轻提示告知。
5. **闭环在本页**：仓位条、结算结果、领取按钮都在所选期卡下面，不必去持仓页。
6. **少即是多**：盘口默认折叠；历史列表默认只展示最近 12 期；规则一行可展开；不在卡上堆低频信息（持有人 / 成交明细留在详情）。

## 4. 页面设计

### 4.1 结构（自上而下）

```
标题 · 周期 · 标的                          ← 沿用
规则一行：参考价 = 开盘价，到期价高于参考价则"涨"  [展开]   ← 取所选期事件 rules，点开看全文
[ 期轨道 ]  更早 ▾ │ 09:00▲ 09:05▼ │ 09:10 ●进行中 │ 09:15 │ 09:20 │ 09:25 │ 更多 ▾
[ 所选期卡 ]                                ← 按状态四种形态，见 4.3
[ 我的仓位条 ]                              ← 该期有仓位才出现，见 4.4
[ 走势卡 ]  价格 / 概率 / K 线              ← 跟随所选期
[ 盘口 ▸ ]                                  ← 折叠块，展开 = OrderBookView
[ 历史窗口 ]  最近 12 期 + 加载更多           ← 点一行 = 选中那一期
```

### 4.2 期轨道

- 横向滚动芯片，自动滚到所选期；芯片 = 时间 + 状态记号：历史期结果圆点（涨绿 ▲ / 跌红 ▼ / 待结算灰 ●）、当期脉冲点、未来期空心。
- 我在某期有仓位 → 芯片右上角小圆点"我"，一眼找到自己押过的期（路径 D、E）。
- 左端"更早"、右端"更多"各打开一个底部面板（`Sheet`）：列出历史期（时间、涨 / 跌、参考价 → 结算价、我的结果）与全部已拉到的未来期；历史面板底部"加载更多"。
- 芯片尺寸按拇指区做（高 36、最小宽 64、间距 8）；可访问性标签形如"09:15 至 09:20，未开始"。

### 4.3 所选期卡的四种形态

| 状态 | 头部 | 价格区 | 动作区 |
| --- | --- | --- | --- |
| 进行中 | 徽章"进行中" + 窗口；倒计时大字"剩余 02:31"，最后 30 秒橙色 + "即将结束" | 参考价 $78,412.30；当前价 $78,378.22 与差值（−$34.08，红 / 绿表示当前是跌方 / 涨方领先） | "涨 55¢" / "跌 46¢" 两个大按钮；无报价时按钮文字"涨 · 暂无报价"并在下方提示"暂无挂单，市价单可能无法成交"；次级链接"查看详情" |
| 未开始 | 徽章"未开始" + 窗口；"09:15 开盘 · 04:29 后开始" | 参考价"开盘时确定"，一句说明"开盘价将作为本期参考价" | 与进行中相同的涨 / 跌按钮（平台 `acceptingOrders=true` 时），按钮上方一行"提前下注"；`acceptingOrders=false` 时按钮禁用 + "该期尚未开放下单" |
| 已结束 · 结算中 | 徽章"结算中" + 窗口；"已结束，等待结算价" | 参考价；结算价"待定" | 无下单按钮；"查看详情" |
| 已结算 | 徽章"涨" / "跌"（或阶段异常：`periodResultLabel` 的失败 / 暂缓） + 窗口 | 参考价 → 结算价（差值）、取价来源 | "查看详情"；仓位结果在仓位条 |

- 非当期时卡片右上角有"回到当期"胶囊；当期不显示。
- 当前价与差值从走势卡头部移到这里（走势卡头部不再重复），价格图仍画参考价基准线。
- 地区受限：按钮禁用 + `RegionNotice`（沿用）。未启用预测账户：点按钮走现有 OrderSheet 的启用引导（不变）。

### 4.4 我的仓位条

- 数据：`usePositions(address, includeClosed=true)` 过滤 `marketId === 所选期.marketId`；同一期涨跌都持有时各一行。
- 形态：
  - 进行中 / 未开始：`涨 12 份 @ 55¢ · 现值 $7.20（+$0.60）`。
  - 结算中：`涨 12 份 · 等待结算`。
  - 已结算赢：`赢 · 可领取 $12.00` + 按钮"领取"（`useRedeem`，与持仓页同一条链路；领取成功 toast，失败原文）。
  - 已结算输：`输 · 12 份归零`（清零入口留在持仓页，不在这里做）。
- 只对已启用预测账户的用户渲染；未启用 / 未登录不出现。

### 4.5 跟随与翻期（页面状态机）

```
跟随当期（默认） ──用户点任一期──▶ 固定所选期 ──点"回到当期"──▶ 跟随当期
```

- **跟随当期**时倒计时归零：
  1. 立刻重拉分期（不等 15 秒轮询），旧当期卡切成"结算中"形态，等待新当期到达（最长约一次请求）。
  2. 新当期到达：我在刚结束的那期**没有仓位** → 自动切到新当期，轨道滚动，底部轻提示"已切到 09:15–09:20"；
     **有仓位** → 停在已结束期看结算，卡上多一个"下一期已开始 · 去看"按钮，点了回到跟随。
- **固定所选期**时：那期结束后仍停留（结果面板 + 仓位条），"回到当期"一直在。
- 用户固定选中的是"下一期"，它到点变成当期 → 选择状态自动清空回到跟随（它本来就是当期），避免它结束时又卡住一次。
- 走势卡随所选期切换：价格图窗口 = 所选期窗口；概率 / K 线用所选期市场。历史期的逐笔价格超出 RTDS 记录范围（history 只有最近 360 个 tick）时，
  价格模式显示"该期逐笔价格已超出记录范围，请看 K 线"，K 线按 `endTime = 该期结束` 拉取。

### 4.6 下单面板（OrderSheet）

- 头部两行：`BTC 5 分钟涨跌 · 涨` / `09:15–09:20 · 未开始 · 04:29 后开始`（倒计时在面板里继续走）。
- 面板打开期间该期结束（倒计时归零）：顶部提示"本期已结束，无法下单"，提交按钮禁用；避免提交到已结束期再被平台拒绝。
- 成功提示带期窗口："已买入 涨 · 09:15–09:20"。
- 其余（金额 / 限价 / 预览 / 启用引导 / 地区限制）不变。

### 4.7 盘口（折叠块）

- 默认收起，标题行显示"盘口 · 买一 55¢ / 卖一 56¢"（有报价时），点开 = `OrderBookView`（Yes / No 切换、点价进限价单）。
- 展开状态在本次停留内记住（切期不收回）。
- 为什么不跳详情下单：详情页按单个事件组织，一期一个事件，切期要退回再进；它的走势图是该市场的 Yes 价历史，刚生成的 5 分钟市场
  没有成交时是空的；参考价、期轨道、标的价格线都不在详情页。持有人 / 规则全文 / 成交明细这些低频信息仍从"查看详情"进入。

### 4.8 系列卡（列表页）

- 当期行下加一行"下一期 09:15 · 可提前下注"（下一期存在且 `acceptingOrders` 时；否则只显示时间）。
- 卡片上的涨 / 跌按钮只对当期；点卡片进系列页后默认跟随当期。
- 最近 5 期结果小序列（▲▲▼▲▼）对"看节奏"有用，但每张卡多一次历史请求，列表页先不做，列入备选（§9）。

### 4.9 持仓页入口

- 平台持仓响应带 `seriesSlug` / `seriesRecurrence`（网页版 `pmPositionsToPositions` 读取；App 的 `data-positions.ts` 契约补这两个字段）。
- 两者同时非空 → 该仓位行的"进度 / 详情"改为进系列页，参数 `periodMarketId = position.marketId`；只有其一 → 维持进详情（与网页版 `resolvePositionHref` 同一规则）。
- 系列页收到 `periodMarketId`：在当期分页与历史第一页里找该期，找到 → 固定选中；找不到（已翻出分页范围）→ 留在当期并提示"该期已不在最近记录中，可在'更早'里查找"。这是导航定位与提示，不是数据兜底。
- 仓位行标题：周期市场显示"BTC 5 分钟涨跌 · 09:10–09:15 · 涨"（窗口由 `endsAt` 与周期反推），普通市场不变。

### 4.10 空态与错误

| 情形 | 表现 |
| --- | --- |
| 分期接口失败 | 轨道位置显示错误行 + 重试；卡片不渲染 |
| 历史加载更多失败 | 列表底部错误行 + 重试，已加载的保留 |
| 新当期迟迟未生成（重拉后仍无进行中 / 未来期） | 卡片"下一期尚未生成，请稍后"，轨道保留历史；30 秒后自动再拉一次 |
| 所选期市场无报价 | 按钮"涨 · 暂无报价" + 提示，不禁用（限价单仍可挂） |
| 标的无法识别 | 走势卡沿用"无法识别标的"，其余不受影响 |
| 地区受限 / 检查失败 | 沿用 `useRegionGate`：按钮禁用 + 提示 + 重试 |

### 4.11 开关与规则

- 全部在 `PredictSeries`（`ModuleGate module="predict"`）内；持仓页入口本身在预测页签内。
- 不写兜底：未来期没有参考价明示"开盘时确定"；定位不到的期明示原因；失败显示错误行 + 重试。

## 5. 数据与改动清单

### 5.1 数据

- `listSeriesPeriods(seriesId, "current", 8)`：进行中 + 未来 7 期（轨道 3 期 + "更多"）；15 秒轮询不变，倒计时归零时手动 `refetch`。
- `listSeriesPeriods(seriesId, "closed", 12, cursor?)`：历史分页，网关补 `cursor` 入参与 `{ items, nextCursor }` 返回（平台响应已带 `nextCursor`）。

- K 线契约增 `endTime` 入参（RTDS `/api/v1/candles?endTime=`，网页版已用）。

## 6. 与网页版差异（有意为之）

1. 有仓位的期结束时不自动跳走（网页一律跟到新当期）。
2. 仓位条与领取放进系列页（网页只在持仓页领取）。
3. 面板内该期结束即禁用提交（网页交给平台拒单）。
4. 盘口默认折叠（网页展开）。

## 7. 验证

- 单测：§5.2 测试列。

### 7.1 结果（2026-09-08）

- 单测：`series-screen.spec.tsx`（跟随 / 未来期提前下单 / 回到当期、已结算结果面板、持仓深链定位与缺失提示、仓位条与领取）、
  `series-card.spec.ts`（周期解析、周期仓位判定、窗口反推、下一期、翻期决策）、`order-sheet.spec.tsx`（期上下文、到期禁用）、
  `positions-screen.spec.tsx`（标题带窗口、进系列页）、`market-list-screen.spec.tsx`（"下一期"行）、网关与契约（分页 cursor、系列字段、`endTime`）；
  全量 jest 106 套 735 例、lint、typecheck、format 通过。
- 实现与设计的两处收敛：
  - 从持仓定位不到那一期时用页内提示行而不是 toast（toast 几秒就没了，用户回头看不到原因）。
  - 标的认不出来时所选期卡不显示当前价（没有订阅，显示 "—" 只会误导）。
- 模拟器记录见下方"模拟器"小节（发布后补）。

## 8. 已确认（2026-09-08，按建议方案）

1. 未来期允许在 App 下单（网页允许；平台 `acceptingOrders=true`）。
2. 系列页直接拉起下单面板 + 折叠盘口，不跳详情；"查看详情"保留给持有人 / 规则全文 / 成交明细。
3. 翻期规则：有仓位的期结束后停留看结算、无仓位自动跟到新当期（§4.5）。
4. 仓位条与领取进系列页（§4.4）；输的清零仍只在持仓页。

## 9. 备选（本轮不做）

- 系列卡最近 5 期结果小序列（每卡多一次历史请求）。
- 结算 / 开盘的本地通知（需要推送策略与开关，另立需求）。
- 面板内"一键押下一期"（下单成功后直接切到下一期并预填相同金额）；先看真实使用再定。
