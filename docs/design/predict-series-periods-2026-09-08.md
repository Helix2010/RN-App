# 周期市场：多期浏览与交易 方案

日期：2026-09-08 · 状态：待确认 · 范围：RN-App（系列页、系列卡、网关分页）

## 1. 问题

App 的系列页只有"当期窗口"一张卡：`pickCurrentPeriod` 选出进行中（或最近的未来）一期，只有这一期能进详情下单；
历史窗口只列结果，未来窗口完全看不到。周期性（每 5 分钟一期、可以提前对下一期下注）没有体现出来。

网页版（`app/predict/crypto/[seriesSlug]/_content.tsx`）的做法：

- **期轨道**：左侧最近几期历史（涨 / 跌 结果圆点 + "更早"菜单，可加载更多），中间当期（进行中，脉冲点），右侧未来 3 期
  （没有进行中时 4 期），更多未来期在"更多"菜单里。
- **任意一期都可选**：选中后整页（窗口、参考价、倒计时、图表、交易面板、盘口）都切到那一期；不选时自动跟随当期（倒计时归零拉新一期并切过去）。
- **未来期可以交易**：交易面板只要该期市场存在且窗口没结束就显示（`market && !periodEnded`）。平台对未来期市场
  `acceptingOrders = true`、代币已生成（dev 核实：当期后 5 期都是 published 且可下单）。未来期的参考价在窗口开始时才确定，
  显示"开盘时确定"。
- **已结束期**：交易面板换成结果面板（参考价、结算价、涨 / 跌、来源）。
- **持仓跳转**：`?event=<该期事件 slug>` 定位到用户持仓那一期（周期市场一期只活几分钟，用户看持仓时那期多半已结束）。

## 2. 方案（App）

### 2.1 数据

- `listSeriesPeriods(seriesId, "current", 8)`：进行中 + 未来 7 期（网页轨道 3 期 + "更多"）。当期 15 秒轮询不变。
- `listSeriesPeriods(seriesId, "closed", 12, cursor?)`：历史分页。平台响应已带 `nextCursor`（`/periods?closed=true&limit&cursor`），
  网关补 `cursor` 入参与返回值：`{ items, nextCursor }`。
- 期状态统一用 `periodPhase(period, now)`：`live` / `upcoming` / `ended`（已有）。

### 2.2 系列页结构

```
标题 · 周期 · 类型
[ 期轨道 ]  ◀ 更早 ▾  ●●●  | 09:05–09:10 ● | 09:10 | 09:15 | 09:20 | 更多 ▾
[ 所选期卡 ]
  状态徽章（进行中 / 未开始 / 已结束）+ 窗口 + 倒计时（剩余 / 后开始 / 已结束）
  参考价（未来期："开盘时确定"）· 结算价（已结束期）
  进行中 / 未来期：涨 / 跌 价格 + 两个下单按钮（直接拉起 OrderSheet，不再跳详情）+ "查看盘口与详情"链接
  已结束期：结果面板（涨 / 跌、参考价 → 结算价、取价来源、该期我的仓位（若有））
  非当期时显示"回到当期"按钮
[ 走势图卡 ]  价格图窗口 = 所选期窗口；概率 / K 线跟随所选期市场
[ 历史窗口列表 ]  保留，点一行 = 选中那一期；底部"加载更多"
```

- **期轨道**：横向 `HorizontalScroll` 芯片。历史侧只放最近 3 期结果圆点（涨绿 / 跌红 / 待结算灰），"更早"打开底部面板
  （`Sheet`）列历史期并可加载更多；未来侧放 3 期时间芯片，"更多"打开底部面板列全部已拉到的未来期。
- **跟随当期**：`selectedPeriodId` 为 null 时跟随 `pickCurrentPeriod`；用户选了某期就固定在那一期（它结束后仍留在那，
  显示结果面板与"回到当期"），与网页一致。
- **交易**：所选期 `phase !== "ended"` 且 `market.acceptingOrders` 且地区允许 → 显示涨 / 跌下单按钮，点击 `OrderSheet.open(market, outcome)`
  （与详情页、持仓页同一个 sheet）。未来期下单前在 sheet 头部标注"未开始 · HH:MM 开盘"，避免误以为是当期。
- **盘口**：所选期卡下方放"盘口"区块（复用详情页的 `OrderBookView` + `useOrderBook(marketId)`，Yes / No 切换、点价进限价单），
  走势图已在本页（标的价格 / 概率 / K 线）。这样系列页 = 周期市场的完整交易面：期轨道 + 走势 + 盘口 + 下单，与网页版一致
  （网页在系列页内也是 TradeForm + 可折叠的盘口 / 成交明细）。
- **为什么不跳详情下单**：详情页按单个事件组织，一期一个事件，切下一期要退回再进；它的走势图是该市场的 Yes 价历史，
  刚生成的 5 分钟市场没有成交时是空的；参考价、期轨道、标的价格线都不在详情页。持有人 / 规则 / 成交明细这些低频信息仍从
  "查看详情"进入。下单面板本身已按盘口深度算成本与最差价（`previewOrder`），不看盘口也不是盲下。
- **参考价**：未来期 `priceToBeat` 为 null 时显示"开盘时确定"，不是 "—"。

### 2.3 系列卡（列表页）

- 当期行下加一行"下一期 09:20 · 09:25"，让列表页就能看出是周期性的；点卡片进系列页后默认仍是当期。
- 卡片上的涨 / 跌按钮只对当期（保持现状：未来期在系列页交易）。

### 2.4 持仓入口

- 持仓页里周期市场的仓位，"进度 / 详情"改为进系列页并带 `periodEventId`，系列页首次匹配到该期就选中它（网页版的 `?event=`），
  用户能看到自己那期的结算。匹配不到（已翻出分页范围）就留在当期，不报错——这是导航定位，不是数据兜底。

### 2.5 开关与规则

- 全部在 `PredictSeries`（`ModuleGate module="predict"`）内；地区限制沿用 `useRegionGate`；不接单（`acceptingOrders=false`）不给按钮。
- 不写兜底：未来期没有参考价就明示"开盘时确定"；历史分页失败显示错误行 + 重试。

## 4. 需你确认

1. 未来期是否允许在 App 下单（网页允许；平台 `acceptingOrders=true`）。方案默认允许。
2. 系列页直接拉起下单面板并内嵌盘口（不跳详情）是否可接受；详情仍可从"查看详情"进入看持有人 / 规则 / 成交。
   备选：只跳详情——实现最省，但切期要来回退进、详情页没有标的价格线和参考价，5 分钟市场上体验明显差。
3. 历史侧默认显示 3 个结果圆点 + "更早"面板，是否够用。
