联调、回归和多设备验证用的共享测试账户。**仅限测试网**，任何时候都不要往这里转主网资产。

助记词不写进仓库：一旦提交就永久留在 git 历史里，任何拿到仓库的人都能控制这个地址。即使如此它也只能当一次性测试身份用：

- MUST NOT 往这个地址转任何主网资产或有价值的代币；
- MUST NOT 用它连接生产环境的第三方 DApp 或签署有真实后果的授权；
- 需要"干净"钱包的用例（首次创建引导、备份验证、恢复态）自行在设备上新建，不要复用这个；
- 这个地址在链上的任何余额都视为可丢失。

## 2. 导入步骤

App 游客首页 →「连接钱包」→「导入钱包」→ 助记词标签页 → 粘贴 12 词 → 出现派生地址预览后点「导入」→ 回到登录面板点签名登录。

用 adb 驱动时注意：`adb shell input text "词1%s词2%s…"` 之后 RN 的受控输入会少一次变更事件，导致预览不出现、导入按钮保持禁用。补一次 `input keyevent KEYCODE_SPACE` 再 `KEYCODE_DEL` 即可让状态跟上。

## 4. 多设备同账号

同一助记词在多台设备导入后，各设备各自完成一次签名登录，服务端按地址识别为同一账号，会话与安装记录各设备独立（可在管理端「安装与设备」查看与吊销）。2026-09-10 在上述四台设备上验证通过，四台首页显示的活跃地址一致。
