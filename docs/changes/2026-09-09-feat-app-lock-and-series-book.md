# 应用锁定页重设计 + 周期市场盘口与报价（2026-09-09）

- 类型：feat / fix · 模块：security、predict（仍受 `modules.predict` 约束）
- 发布：1.2.11 基线 OTA rev 9 `ota_XJc8CalLmOeqnmaUDKAAYw`（a56a79a）、rev 10 `ota_uP4MZO7dZT61Anc6u9wfEQ`（7ffc297），均 immediate

## 1. 应用锁定页（`features/security/app-lock-gate.tsx`）

用户反馈"指纹外围的圈看着比较 low"。去掉图标底盘：

- 不再有 112dp 圆形底盘和描边，指纹 / 面容 / 密码图标直接以 76dp 呈现，用留白建立层级。
- 图标 1.4 秒一次呼吸（透明度 0.45 ↔ 1）提示可点；验证失败时停止呼吸、变 `$danger` 并轻微左右晃动。
- 标题升到 26dp / 800 字重并收紧字距，副标题降为弱色说明。
- 底部新增一颗主色按钮"使用指纹解锁 / 使用面容解锁 / 输入设备密码解锁"（按设备能力取文案），解锁动作不再只能靠"轻触图标"这种隐性交互。
- 失败文案占固定一行高度，出现时按钮不跳位。品牌 logo 缩到 40dp 顶部居中。

文案：`security.unlock.hint.*`（提示语）→ `security.unlock.with.*`（按钮文案）。

## 2. 周期市场盘口与涨 / 跌报价

用户反馈"盘口是不是可以默认展示""点击涨跌按钮弹层有延迟"。

- **盘口默认展开**（`series-screen.tsx`）：5 分钟这类市场里深度就是主要决策信息，不该多点一次。事件详情页本来就默认停在"盘口"页签，两处一致。
- **涨 / 跌按钮按订单簿报价**（`series-period-card.tsx`）：原来只读平台事件价 `yesPriceCents`，而周期市场的事件价常常为空、簿里却有挂单，于是按钮显示"暂无报价"、点开弹层却有价——两处不一致。现在买涨取卖一、买跌取 100 − 买一，与下单弹层同一口径；簿为空才回落事件价，两者都没有才是"暂无报价"。
- **预热费率**：进入周期页就取该市场费率（`useFeeBps`，10 分钟缓存），下单弹层第一帧就有手续费和均价，不再先显示"—"再补。订单簿本来就与页面共用查询键，弹层打开即命中缓存。
