# Fix: app-lock-prompt-not-showing

状态：Implemented（自动化验证完成；模拟器复现不出原现象，真机未运行）

## 现有行为（用户报的路径）

冷启动弹出系统验证 → 取消 → 在锁屏页点指纹，又弹出来 → 再取消 → 过一会儿手机息屏
锁机 → 解锁手机回到 App → 再点指纹，**不弹了**。

`AppLockGate` 里拉起验证的那段有三个问题，任何一个都会让用户看到"点了没反应"：

1. **防重入标记会卡死**。`prompting` 在 `await authenticate()` 返回后才清。息屏 / 切走时
   系统会把 BiometricPrompt 一起收掉，而 expo 那个 Promise 可能再也不 resolve
   （Activity 被重建时尤其如此），标记就永远停在"正在弹"，之后每次点图标都被自己挡掉。
2. **系统会挡掉排太近的请求**。Android 的 BiometricPrompt 一次只认一个：上一个还在收起、
   或 Activity 刚回到前台时再拉起，系统立刻回一个 cancel，界面上什么都不出现。代码把它
   当成"用户取消"，不重试也不提示。
3. **回前台不补弹**。锁还在时从后台回来（上次弹窗被切走打断、或用户取消后切走），
   页面上只剩一个图标，要用户自己去点。

## 预期行为（验收条件）

1. 进后台时立刻放开防重入标记——弹窗那时已经没了；
2. 两次弹窗之间留出收起时间（350ms）；秒回（<500ms）的取消判为系统挡掉，自动重试一次；
3. 人点的取消（慢回来的）不重试，停在锁屏等用户操作；
4. 回到前台时锁还在就自动补弹一次；
5. 验证失败后仍能再次拉起（标记放在 `finally` 里清）。
