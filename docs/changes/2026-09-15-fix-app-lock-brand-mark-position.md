# Fix: 应用锁定页的 logo 孤零零钉在最上面

状态：Implemented（`pnpm check` 全绿；模拟器上截图核对）

## 现象

用户反馈锁定页「图片显示的有点偏向上面了」。截图量过：40pt 的 logo 紧贴状态栏下方
（y≈240px），下一个元素「App locked」在 y≈900px——中间空掉约 560px，logo 在那儿是
个孤立的小方块，跟页面其余部分没有关系。

## 原因

`app-lock-gate.tsx` 把 logo 单独放在一个贴顶的 `Stack` 里，标题与副标题在下面
`flex={1}` 的居中容器里。两者不是一簇，logo 只是被顶到了最上面。

而基座里同类页面的既定构成是**一簇居中的 logo + 标题**：
`app/launch-screen.tsx` 是 104pt logo + 标题居中，关于页是 `BrandMark size={72}` + 标题。
锁定页概念上就是启动页的兄弟页，却没照这套来。

## 处理

把 `BrandMark` 移进居中容器、放在标题上方，尺寸 40 → 72（对齐关于页），
容器 `gap="$5"`，标题与副标题另包一层 `gap="$2"` 保持原有的紧密关系。
顶部 `paddingTop` 从 `insets.top + 28` 收到 `+16`——那里已经没有内容了。

解锁区仍留在屏幕下三分之一（拇指区），这一点没动。

## 影响

纯布局，无原生变更，可走 OTA。
