# Fix: app-lock-unlock-affordance

状态：Implemented（自动化验证完成；模拟器亮色 / 暗色录屏核对，真机未运行）

## 现有行为

锁定页（`AppLockGate`）上有两个动作完全一样的入口：屏幕中间那个可点的大图标，和底部
一颗整宽主按钮「使用指纹解锁」，点哪个都是调 `unlock()` 拉起系统验证。

- 图标停在屏幕正中，单手握持时偏高；
- 图标的"可点"提示只有透明度 1 ↔ 0.45 的呼吸。图标是单色的，透明度变化看上去更像
  渲染没画完，不像可以点；
- 亮色 / 暗色下这个提示的可见度没有区分。

## 预期行为（验收条件）

1. 去掉底部的「使用指纹解锁」按钮，图标本身就是解锁按钮；
2. 图标没有文字标签，下面保留一行浅色说明（按验证方式区分：指纹 / 面容 / 虹膜 / 设备密码），
   取消系统验证后用户知道可以点它；
3. 解锁区落在屏幕下三分之一（拇指区），横向居中；
4. 提示动效在亮色与暗色下都清楚可见；
5. 验证失败时动效停止，仍是红色图标 + 轻晃 + 失败文案。

## 改动

- `app-lock-gate.tsx`：删掉 `PrimaryButton`；解锁区（图标 + 说明 + 失败文案）移到页面底部，
  标题与副标题留在上方居中；点按区域 152×152。
- 动效改成两部分：图标缩放 1 ↔ 1.12、透明度 1 ↔ 0.62；外加两圈主色描边涟漪，错开半个
  周期（每圈 2s）从图标向外扩散后消失。涟漪用描边不用实心圆——实心的静止时像给图标
  加了个底盘（原设计就不要底盘），暗色下还发闷。
- 主题区分：涟漪最亮时的透明度亮色 0.62、暗色 0.68（`HALO_OPACITY`），主色描边在两种
  底色上都看得清。主题名从 `useThemeName()` 取，design-system 补上这个导出。
