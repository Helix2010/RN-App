# 预测市场覆盖补全：交易闭环缺口、发现层、策展与周期市场

日期：2026-09-08

设计与覆盖矩阵见 `docs/design/predict-coverage-review-2026-09-08.md`（§4 第 1–3 项）。

## 需求

对照 C 端（pm-cup2026 user-dapp）把 App 预测市场缺失的能力补齐，且每一项都严格受租户开关 `modules.predict` 约束。

## 现有行为

- 列表只有分类 + 三种排序，没有搜索、状态筛选、收藏；置顶卡只取 `featured=true` 的第一条。
- 详情只显示首个标签、总成交量；持有人页签只有一个计数；多结果事件用 chip 切换，看不到每个结果的成交量与结算结果。
- 持仓盈亏固定 1d；输掉的仓位无法清掉；领取中没有进度文案。
- 结算页对平台的取消阶段不识别；没有阶段文案。
- 没有周期市场（BTC 5 分钟涨跌等）。

## 预期行为

- 列表：本地搜索、交易中 / 已结束 / 全部、收藏（本机持久化）、24h 成交量 / 流动性排序；默认标签下展示平台策展的
  精选轮播、高概率 / 今日热门榜、周期市场卡。
- 详情：完整标签、24h 成交量与流动性、每个结果的成交量与结算结果、市场级规则、持有人榜（data `/holders`）、收藏星标；
  平台不接单时不给下单入口。
- 持仓：盈亏区间 1d / 1w / 1m / 全部；零收益仓位一键清理；领取中文案。
- 结算：取消状态与阶段文案。
- 新页面 `PredictSeries`：当期窗口（参考价、倒计时、涨 / 跌）与历史窗口；交易复用事件详情。

## 开关约束

- `PredictSeries` 套 `ModuleGate module="predict"`；列表页本就只在预测页签内挂载。
- 新查询 `useCuratedEvents` / `useSeriesList` 带 `enabled`，只在默认标签 + 交易中 + 非收藏视图下请求。
- 收藏、搜索、榜单是本地计算，不增加平台请求。

## 风险

- `/curation/events`、`/series*`、data `/holders` 在租户头下的可用性未在 dev 联调确认（设计文档 §5）；
  接口失败时对应区块显示错误行并可重试，不影响列表主体。
- 收藏视图逐个取事件，上限 50 条；单个失败只提示条数，其余照常显示。
- 首页系列最多 8 个，每个系列卡 15 秒轮询当期；所有倒计时共用一个秒表。
