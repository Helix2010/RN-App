# Feature: 口令设置进开通流程，并在模拟器上走完整条路

状态：Done（模拟器实测通过，四个只有真机才暴露的问题已修）

涉及仓库：RN-App。方案：`docs/design/wallet-key-hardening-2026-09-12.md` §3.5、§3.6。

## 放在哪一步，为什么

排在**备份完成之后**。忘记口令无法找回，而换锁屏或重录生物识别之后系统会作废那把认证绑定的密钥，届时只能靠口令重新打开钱包。放在用户已经抄下助记词之后，最坏情况才有退路；反过来的顺序等于给一部分用户留一颗定时炸弹。

**可以跳过。** 这是加固，不是门禁。做成必填只会让一部分用户随手输一串记不住的东西，那比不开更糟。"忘了找不回来"这句话放在按钮之前，有用例盯着。

## 金库怎么向界面要口令

要口令的时机不属于任何一个页面：系统作废了密钥，或者用户要查看助记词。金库不能 import 任何 UI——它的能力边界只有"安全存储 + 身份验证 + 随机数"。所以用一个全局的 promise 通道，金库拿到的只是一个函数。

- 输错会再问一次并告诉界面"上次错了"，连错三次放弃本次操作。
- 取消不是输错，立刻结束不再追问，抛 `WalletPassphraseRequiredError`。
- 解锁 WK 和读助记词两条路共用同一个循环，"错三次就放弃"只有一处实现。

## 模拟器实测暴露的四个问题

单测全绿、类型和 lint 干净的情况下，这四个在真机上才现形：

1. **开启口令要跑四次 scrypt。** `sealWrapKey` 为了算校验值又派生了一遍，读回来核对再派生一遍，重新加密助记词又一遍。scrypt 是故意做得很慢的，四倍就是四倍的等待。改成派生一次并把密钥交给调用方，`openWrapKeyWith` 在已有密钥时直接开。
2. **KDF 参数在手机上完全不能用。** 实测：N=2^14 一次约 20 秒，N=2^13 约 10 秒；Node 上 2^15 只要 90 毫秒。Hermes 没有 JIT，比 Node 慢两个数量级，服务端 keystore 的 2^16 照搬过来就是死。定在 2^13，并把这张表写进 `passphrase.ts`——下一个人不用再测一遍。
3. **按下去 10 秒没有任何反馈。** 一个变灰的按钮，用户以为没按上。加了"正在启用…请不要离开"。这一条我自己先被骗了一轮，以为是死锁。
4. **要口令那一层被键盘整个盖住。** 底部抽屉的键盘避让接不住这个场景：抽屉停在原位，用户看得见标题却按不到按钮。改成居中弹层配 `KeyboardAvoidingView`，和强制更新那一层同一个做法——它本来就该是阻断式的。`autoFocus` 也去掉了，它会在抽屉还在进场时就把键盘顶起来。

## 模拟器上验过的

线上签名密钥签出来的发布包，`sdk_gphone64_x86_64`：

| 项 | 结果 |
| --- | --- |
| 新建钱包默认词数 | 24，选择器默认选中"24 个词（更安全）" |
| 备份页 | 24 格，标题"抄写这 24 个单词" |
| 备份完成之后 | 进入设置钱包口令页 |
| 跳过 | 回到首页，不强制 |
| 口令太短 | 当场显示"口令至少 8 位"，按钮不可用 |
| 启用口令 | 约 10 秒完成，期间显示进行中文案 |
| 启用之后解锁 | 弹出居中的输入层，键盘不遮挡，输入口令后 2 秒解锁 |

这台模拟器没有录入生物识别，所以认证绑定的那条路不可用，每次解锁都会走口令——正好把恢复路径也验了一遍。

## 只有单测覆盖、没在设备上跑到的

口令输错的重试反馈、连错三次放弃、以及"开了口令之后签名不问口令"。前两条在 `keystore-vault-passphrase.spec.ts`，第三条在 `keystore-vault-entry-split.spec.ts`，都有用例；设备上没能复现出触发时机。

## 安全中心里的入口

开通流程可以跳过，所以安全中心里有一行「钱包口令」：没设过就标出"未设置"并可以点进去补；已经开了只显示状态，**不给再点一次的入口**。

不做"改口令"是有意的：换口令要把信封整个换掉并重新加密助记词，中间任何一步出错就是钱包打不开。真要支持它，那是一条独立的、带确认与回滚的流程，不是在这一行上加个跳转。

口令页的返回统一走 `goBack`，不再写死 `popToTop`——从安全中心进来的人要回安全中心，写死会把他甩回首页。退不回去时（开通流程里上一页被 replace 掉了）才 `popToTop`。

## 没在设备上跑到的

- 口令输错的重试反馈、连错三次放弃、"开了口令之后签名不问口令"：都有用例，设备上没复现出触发时机。
- 安全中心那一行：这台模拟器上钱包登录始终没走完（服务端能收到这台设备的心跳，1.3.11 build 47 在册，所以不是网络问题），而安全中心要登录后才进得去。两条用例覆盖了"未设置可点进去"和"已启用不可点"。
