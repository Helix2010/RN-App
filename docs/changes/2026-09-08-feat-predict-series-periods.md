# 周期市场：多期浏览与交易

日期：2026-09-08 · 设计：`docs/design/predict-series-periods-2026-09-08.md`（第 3 稿，§8 四项已按建议确认）

## 需求

系列页只有"当期窗口"一张卡，只能对当期下单，未来期看不到、历史期只列结果；周期性（每 5 分钟一期、可提前押下一期）没有体现。网页版允许选任意一期并交易未来期。

## 预期行为

- **期轨道**：更早 ▾ │ 历史 3 期（▲ / ▼ / • 结果记号）│ 当期（绿点，描边）│ 未来 3 期 │ 更多 ▾；我押过的期带角标；选中的期自动滚到可见位置。"更早"面板列历史期并可加载更多，"更多"面板列全部未来期。
- **所选期卡四种形态**：进行中（倒计时，最后 30 秒橙色 + "即将结束"；当前价与较参考价）、未开始（"HH:MM 开盘 · 后开始"，参考价"开盘时确定" + 一句说明，"提前下注"）、结算中（"已结束，等待结算价"）、已结算（涨 / 跌徽章，参考价 → 结算价，取价来源）。涨 / 跌两个大按钮直接拉起下单面板；无报价时按钮写"暂无报价"并提示市价单可能无法成交；平台未开放接单时禁用并说明；地区限制沿用。
- **我的仓位条**：所选期有仓位才出现；进行中给份数 / 均价 / 现值 / 盈亏，结算中"等待结算"，赢"可领取 + 领取按钮"（与持仓页同一条领取链路），输"归零"，已领取"已领取"。
- **跟随与翻期**：默认跟随当期；倒计时归零立即重拉分期；新当期到达时，刚结束那期有仓位就停在那看结算并给"下一期已开始 · 去看"，没有就自动切过去并轻提示"已切到 HH:MM – HH:MM"；用户手选的期固定显示，"回到当期"回来；手选的"下一期"到点成为当期后自动回到跟随；下一期迟迟未生成显示"下一期尚未生成，请稍后"。
- **下单面板**：标题 = 系列名，副标题 = 期窗口，顶部一行状态 + 倒计时；面板打开期间该期结束 → "本期已结束，无法下单"，提交禁用；成功提示带期窗口。
- **走势卡**：随所选期切换；历史期的逐笔价格超出 RTDS 记录范围时提示"请看 K 线"，K 线按该期结束时间（`endTime`）拉取。当前价与较参考价移到所选期卡，走势卡只画图。
- **盘口**：折叠块，标题行给买一 / 卖一，展开 = 盘口视图，点价进限价单；已结束期不显示。
- **规则一行**：所选期事件的规则，默认一行，"查看规则 / 收起规则"。
- **列表卡**：当期行下"下一期 HH:MM · 可提前下注"。
- **持仓页**：平台持仓带 `seriesSlug` + `seriesRecurrence`（两者同时非空，与网页版 `resolvePositionHref` 同一规则）的仓位标题带该期窗口，点行进系列页并定位到那一期；定位不到（已翻出分页范围）留在当期并提示。

## 数据

- `listSeriesPeriods(seriesId, scope, limit, cursor?)` 返回 `{ items, nextCursor }`；当期取 8 期（当期 + 未来 7 期），历史每页 12 期（`useInfiniteQuery`）。
- 持仓契约增 `seriesSlug` / `seriesRecurrence`；K 线契约增 `endTime`（毫秒）。
- Mock：分期往前 36 期 / 往后 7 期，未来期参考价为 null（与平台一致），历史分页按偏移量 cursor；仓位按市场 id 前缀认出所属系列。

## 开关

全部在 `PredictSeries`（`ModuleGate module="predict"`）内；持仓页入口在预测页签内；地区限制沿用 `useRegionGate`。

## 与网页版差异（有意）

有仓位的期结束不自动跳走；领取放进系列页；面板内到期即禁用提交；盘口默认折叠。

## 风险

- 翻期判断依赖设备时钟与平台窗口时间一致；时钟偏差大时"结算中"形态会提前 / 延后出现，数据本身不受影响。
- 未来期下单依赖平台 `acceptingOrders=true`（dev 核实当期后 5 期都开放）；平台关掉即按钮禁用并说明。
